D SECURE — PACK DE MAPPING DES PHOTOGRAPHIES

Contenu:
- D_SECURE_IMAGE_MAPPING.xlsx : mapping avec miniatures originales, statut, source, ligne et chemin.
- D_SECURE_IMAGE_MAPPING.csv : version lisible par machine.
- images/ : photographies originales extraites et renommées par catégorie + référence.
- PROMPT_AI_STUDIO_ASSOCIATION_STRICTE.md : prompt strict pour AI Studio.

IMPORTANT : les photos sont associées automatiquement à une référence uniquement lorsqu’elles sont ancrées sur la même ligne Excel. L’onglet A_CONTROLER contient les lignes sans image sur la même ligne ou les références non identifiées. Vérifier ces cas avant publication. Aucune image n’a été générée. Les originaux Excel ne sont pas modifiés.
